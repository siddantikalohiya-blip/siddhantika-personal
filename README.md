# Siddhantika Lohiya — Resume Website

This website is based on the one-page CV supplied for this assignment.

## Files
- `index.html` — website structure and resume content
- `style.css` — fonts, colours, spacing, layout, responsive rules and hover states

## Preview
Open `index.html` in a browser.

## Publish using GitHub Pages
1. Upload `index.html` and `style.css` to the root of the existing resume repository.
2. Commit the changes.
3. Open repository Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Choose the main branch and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish the website.

## Important
Review the website after opening it locally. The education entries for IIM Bangalore and Mesa School of Business are both shown as they appear in the supplied CV. No additional work history or qualifications have been added.
